## 0. 设计目标与总原则

目标流程固定为三段：

```
定位（10×10 / 15×15 阵列点坐标）
  → 定量（逐单元光度量提取）
    → 输出（CSV / JSON + 质量控制结论）
```

四条总原则贯穿全部设计：

1. **物理先验优先**：阵列是刚性规则晶格，几何自由度天然很低（一个全局变换 + 极小的逐点残差）。所有几何估计都应收敛到低自由度参数模型，而不是逐点自由回归。
2. **自参照优先**：阵列面板自身携带冗余参照信息（单元间背景、重复单元、已知拓扑）。光度校正尽量利用自参照，而不是依赖外部标定物或训练数据。
3. **传统方法为主干，学习方法为可插拔兜底**：主链路必须在零训练样本下可运行、可测试、可移植；深度模型只放在已有的替换槽位上，失败时可整体禁用。
4. **一切改进必须可证明**：先建评估基准，再做算法改动；每次改动以退化曲线和 A/B 指标说话。

## 1. 当前未解决的关键问题（问题清单）

按"定位 → 定量 → 质量控制 → 评估"四层归类，标注严重度（高/中/低）：

### 1.1 定位层

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| L1 | 主区域检测仍是亮度阈值范式 | 高 | 两档阈值（高分位 / Otsu）解决了"大面板"问题，但对强光照梯度、彩色照明、低对比背景、面板与背景亮度接近的场景仍然脆弱；兜底仍是固定中央框。 |
| L2 | 四角单应把全部几何压在区域检测质量上 | 高 | minAreaRect 的四角来自二值掩膜边缘，受形态学膨胀、边缘反光、阴影影响；1.10 固定外扩把边缘误差直接耦合进比例尺。四角错 1%，全部点位系统性偏移约 1%。 |
| L3 | 晶格一致性模型只有仿射 6 自由度 | 中 | 矫正残差中的透视分量（非仿射）与手机镜头轻微径向畸变无法表达，表现为边角区域的系统性弯曲残差（可达数 px），会被误当作"正常制造公差"留下。 |
| L4 | "多数锁定"失效模式仍存在 | 中 | 一致性校正是多数投票：当初始网格错误但自身规则（如退化为均分网格）且精修救回比例 < 50% 时，仿射拟合会锁定错误网格并撤销正确的局部精修。上一阶段靠改进初始拟合绕开了触发条件，但机制层面未消除。 |
| L5 | 逐点结果没有置信度与来源标记 | 高 | 一个点究竟是"有候选支撑 + 精修成功"还是"晶格模型外推补出来的"，输出中无法区分；下游定量和质量控制无从加权。 |

### 1.2 定量层（与目标差距最大的一层）

| # | 问题 | 严重度 | 说明 |
|---|------|--------|------|
| P1 | 光度量是设备原始 RGB 的裸均值/中位数 | 高 | 不同光照强度、色温、曝光参数下同一目标的读数不可比。这是"不同光照条件下定量不稳定"的直接原因。 |
| P2 | 无光照场（flat-field）校正 | 高 | 面板内的光照梯度（单侧打光、阴影）直接叠加在单元读数上，同一面板左右两侧的同类单元读数可以差出百分之几十。 |
| P3 | 固定方形 ROI 泄漏背景 | 中 | ROI 以点为中心取方窗，单元形状/尺寸变化或点位有 1-2px 偏差时混入单元间背景；中位数只能部分缓解。 |
| P4 | 局部过曝/阴影只有整图统计 | 中 | `saturation_ratio` 是整 ROI 比例，没有"该单元读数已不可信"的逐单元判定；阴影完全没有建模。 |

## 2. V2 总体架构

分六层，层间以显式数据结构衔接，每层可独立测试、独立替换：

```
L0 预处理与光照建模
    输入：原图
    输出：归一化图像、光照场估计 B(x,y)、高光掩膜 M_glare、阴影掩膜 M_shadow
L1 主区域提议（快路径 = 现有两档传统检测；慢路径 = 可选学习型兜底槽位）
    输出：四角初值 + 提议来源标记
L2 晶格几何求解（核心升级：从"四角单应"到"晶格光束法平差"）
    输出：全局几何模型 G、逐点坐标、逐点残差 r_i、逐点来源 source_i、置信度 c_i
L3 光度提取（核心升级：自参照校正 + 自适应 ROI + 逐单元状态）
    输出：逐单元 raw 与 corrected 光度量、SNR、flags_i
L4 质量控制引擎（帧级门控 + 单元级标记，输出机器可读 reasons）
L5 输出层（向后兼容的 result.json / values.csv 增量扩展 + 调试可视化）
```

### 2.1 L2 关键设计：晶格光束法平差（Lattice Bundle Adjustment）

这是几何层的核心创新点，替代"四角单应 + 仿射一致性"两段式：

**模型**：把 (row, col) 晶格索引到原图坐标的映射参数化为

```
p_i = D( H · [col_i, row_i, 1]ᵀ ; k1 )
```

其中 H 为 8 自由度单应（吸收平移/旋转/缩放/剪切/透视），D 为以主点为中心的一阶径向畸变（单参数 k1，可选启用）。总自由度 8–9，由 100–225 个观测点约束，冗余度极高。

**求解流程**（EM 式交替，固定 2–3 轮）：

1. 用现有链路（候选检测 → 旋转扫描 → 轴选择）取得初始网格；
2. 局部精修每个点（现有组件/质心精修），得到观测集 {p_i}；
3. 以 Tukey 双权 IRLS 拟合 H(, k1)，逐点残差 r_i 给出鲁棒权重；
4. 用拟合模型预测全部点位，以预测位置为中心、**用更小的窗口**再精修一轮（窗口随轮次收缩：0.32→0.20 pitch）；
5. 重复 3，收敛后输出。

**关键差异与收益**：

- 四角只提供初值，不再决定最终几何 —— 区域检测的边缘误差（L2 问题）被 100+ 个内部观测稀释；
- 透视与径向分量显式建模（解决 L3），边角系统性残差消失；
- 逐点残差天然给出置信度：`c_i = exp(-(r_i/σ)²)`，σ 为鲁棒尺度（MAD）；
- **"多数锁定"防御**（解决 L4）：引入"候选支撑率"硬指标——最终网格点中，落在某个真实候选（黑帽/顶帽连通域）τ 邻域内的比例。支撑率 < 60% 时拒绝该解，回退并在 QC 中报告，而不是让规则但错误的网格静默通过。这个指标是外部证据，不参与多数投票，因此不会被投票结果绑架。

**逐点来源标记（解决 L5）**：`source_i ∈ {candidate_refined, model_imputed}`；imputed 点照常输出坐标（保证 grid_points 数量恒等于 grid_size²，兼容现有约定），但带 flag 供下游降权。

### 2.2 L3 关键设计：自参照光度校正

定量层的核心创新点：**把阵列自身当作光照参照物**。

1. **光照场估计**：阵列单元只占面板面积的一小部分，单元间背景是同一材质的连续区域。对背景像素（由晶格几何反推的"非单元"掩膜）拟合低阶二维多项式（2 阶，6 系数）或大核形态学背景 B(x,y)。样本少不影响——这是逐图自参照，不需要训练。
2. **平场校正**：`corrected(x,y) = raw(x,y) / B(x,y) × B̄`（乘性，适合反射式光照不均）与 `raw - B + B̄`（加性，适合基线漂移）都输出，由评估基准决定默认（见 §8），另一种保留为可选列。
3. **环形局部背景扣除**：每个单元取"内圆 ROI + 外环背景邻域"（annulus，内外半径按 pitch 比例定义，环与相邻单元不重叠），输出 `roi_median - annulus_median` 作为局部背景差分量。它对残余的局部阴影/渐变最鲁棒，是跨光照一致性的主力指标。
4. **自适应 ROI 掩膜**（中期）：以晶格预测点为中心、在 0.5×pitch 窗口内做局部分割（Otsu / 自适应阈值），但掩膜必须满足几何约束（面积、圆度/方形度、与预测中心的偏移上限），不满足则回退固定形状 ROI。掩膜同时用于剔除 ROI 内的高光像素（M_glare 交集）。
5. **逐单元状态机（解决 P4/P5）**：

```
flags_i ⊆ {saturated, under_exposed, low_snr, glare_contaminated,
           shadow_contaminated, occluded_suspect, imputed_position}
```

判定全部来自可计算量：饱和像素比例、局部 SNR =（单元信号 − 环形背景）/ 背景鲁棒噪声（MAD）、掩膜面积异常、source_i。`occluded_suspect` 的定义：该点为 imputed 且其局部窗口统计与同图其余单元分布显著偏离（稳健 z 分数 > 3.5）。

RGB 之外继续输出 Lab；如后续确认设备端可取得 gamma 信息，可增加线性化列（`corr_linear_*`），当前不强制。

## 3. 继续使用传统计算机视觉的模块（及理由）

| 模块 | 方法 | 理由 |
|------|------|------|
| 主区域快路径 | 两档阈值 + 形态学 + 轮廓先验（现状保留） | 确定性、可解释、微秒级；覆盖大多数受控拍摄场景 |
| 候选检测 | 黑帽/顶帽 + 内部 Otsu + 几何过滤（现状保留） | 形态学滤波恰好匹配"小结构 vs 大背景"的尺度先验，零训练、移动端极廉价 |
| 晶格几何求解 | IRLS/RANSAC 参数模型（§2.1） | 8–9 自由度对 100+ 观测，经典鲁棒估计是该问题的最优工具；学习模型在此没有信息优势 |
| 光照建模与光度校正 | 低阶多项式/形态学背景 + 环形差分（§2.2） | 自参照物理模型，样本无关；这是"少样本"约束下唯一稳妥的定量根基 |
| 局部精修 | 连通域几何约束 + NCC 模板匹配（新增可选） | NCC 对对称结构的亚像素定位成熟且便宜；模板可由本图候选均值在线生成，仍是零训练 |
| 质量控制度量 | 统计量（饱和率、Laplacian、光照场范围、几何 RMSE） | 全部可计算、可标定、可测试 |

一句话：**几何与光度的主链路全部保持传统方法**，因为这两层的问题结构（低自由度参数模型 + 自参照冗余）正是传统方法的主场。

## 4. 可引入的现代方法（2025–2026）及引入位置

严格限定为三个插槽，每个都有明确的"为什么适合本项目"：

1. **区域提议兜底槽（已有架构预留）：SAM 系列轻量变体（MobileSAM / EfficientSAM / SAM 2 小模型）**
   - 用法：仅当传统两档检测无候选或 QC 判定几何失败时触发；对整图做一次类别无关分割，选取"面积/长宽比/亮度先验"最匹配的掩膜，取其 minAreaRect 作为四角初值，后续链路不变。
   - 适合原因：(a) 类别无关分割不需要任何本项目训练数据，直接零样本使用，契合"样本少"；(b) 每次拍摄只推理一次（不是逐单元），端侧成本可控；(c) `detect_chip_region()` 从 V1 起就是声明好的替换点，接入零侵入。
   - 明确不做：不用大型 ViT 主干做逐单元处理；不做在线微调。
2. **合成数据引擎（域随机化）用于评估与可选训练**
   - 用法：扩展 `examples/generate_synthetic_samples.py` 为参数化渲染器（光照梯度、色温、透视、径向畸变、模糊、遮挡、过曝斑、噪声全部可控可播种）。首要用途是 §8 的基准语料；次要用途是若长期需要训练轻量模型（如角点精修小网络），训练完全在合成域进行，真实少样本只做验证。
   - 适合原因：域随机化是"少样本 + 需要泛化"的标准解法；本项目目标结构完全已知（规则晶格），可渲染性极好，合成-真实差距天然小。
3. **保形式阈值标定（conformal calibration）用于 QC 阈值**
   - 用法：QC 的各判定阈值（如 geometry_rmse 上限、SNR 下限）不再手工设定，而是在合成扰动语料 + 少量真实标定集上按目标覆盖率（如"95% 合格图不被误拒"）取分位数。
   - 适合原因：无分布假设、小样本可用、给出的阈值带明确统计语义；实现只是分位数计算，成本近乎为零。

远期可探索（明确标记为低优先级、先评估再投入）：以通用自监督特征（DINO 系）的 patch 相似度做逐单元异常检测（遮挡/污损的无监督判定）。仅在 §2.2 的统计学异常判定被证明不足时才考虑。

## 5. 少样本条件下的可靠性策略

1. **低自由度参数模型**：几何 8–9 DoF、光照 6 系数——参数远少于观测，本质上是"用物理先验替代数据量"。
2. **合成扰动语料 + 退化曲线**：可靠性不靠单点指标，靠"性能随扰动强度的退化速率"（§8），合成语料要多少有多少。
3. **兜底阶梯 + 阶梯遥测**：候选晶格 → 投影峰 → 均分网格；SAM 兜底 → 中央框。每次运行记录实际触发的档位（fallback_tier），语料统计各档触发率——高档位触发率上升本身就是回归信号。
4. **交叉证据校验**：候选支撑率（§2.1）把"内部自洽"与"外部证据"分离，防多数锁定。
5. **蜕变测试（metamorphic testing）**：不需要标注的不变性检查——同一图旋转 3°/缩放 0.9×/亮度 ×1.2 后，输出网格应按已知变换协变、校正后光度量应近似不变。作为 pytest 常驻用例，等价于"免费标注"。
6. **半自动标注闭环（已有工具）**：预测点 → 人工微调 → 版本化金标集（annotations/ 目录 + 清单文件）；金标集只用于验证，不用于训练，避免几张样本被"用穿"。

## 6. 移动端迁移设计

1. **核心链路 OpenCV-only**：L0–L5 主链路不引入 Python 专属依赖，算法层与 I/O 层分离，保证可平移到 OpenCV Mobile（C++/Kotlin/Swift 绑定）。
2. **计算预算表**（设计即约束，每阶段进 CI 计时）：

| 阶段 | 预算（中端 SoC，1600px 输入） |
|------|------------------------------|
| L0 预处理 + 光照场 | ≤ 60 ms |
| L1 快路径检测 | ≤ 40 ms |
| L2 光束法平差（含 2 轮精修） | ≤ 120 ms |
| L3 光度提取（225 单元） | ≤ 50 ms |
| L4/L5 | ≤ 30 ms |
| 合计 | ≤ 300 ms（不含可选 NN 兜底） |

3. **组合复杂度已封顶**：轴选择组合枚举上界 C(count+4, 4)（上一阶段已修），无隐藏指数路径；内存峰值 = 常数 × 矫正图面积。
4. **可选 NN 槽的部署形态**：ONNX 导出 → NNAPI/CoreML/NCNN，int8 量化；模型文件与主程序解耦，缺失时自动降级为纯传统链路（功能不缺失，只降鲁棒性上限）。
5. **桌面-端侧一致性（golden parity）测试**：同一输入在两端产出的 result.json 逐字段比对（坐标容差 ≤ 0.5px，光度量容差 ≤ 1 量化单位），防止移植引入静默偏差。
6. **单线程确定性参考实现**：并行只作为可选加速层，保证任意平台可复现。

## 7. 质量控制机制设计

**两级结构：帧级门控 + 单元级标记**（分别回答"这张图能不能用"与"这张图里哪些单元不能用"）。

帧级输入信号（全部已在 §2 的产物中）：

| 信号 | 来源 | 针对问题 |
|------|------|----------|
| 饱和率 / 欠曝率 | L0 | 过曝、欠曝 |
| 归一化清晰度（Laplacian 方差 / 内容强度） | L0 | 失焦、抖动 |
| 光照均匀度 = 1 − (B_max−B_min)/B̄ | L0 光照场 | 单侧打光、阴影 |
| geometry_rmse、rotation_deg、pitch 偏差 | L2 | 透视/倾角过大、矫正失败 |
| candidate_support_ratio、imputed_ratio | L2 | 遮挡面积过大、错误网格 |
| fallback_tier（0=候选晶格 … 3=中央框） | L1/L2 | 检测退化 |

**决策形式**：可解释规则树（不是黑盒打分）——每条规则独立产生 `reason`（机器码）+ `suggestion`（人读建议），最终状态取最严重级别。示例：`rotation_deg > θ_rot → warn("tilt_high", "降低拍摄倾角")`；`candidate_support_ratio < 0.6 → fail("grid_untrusted", "重新拍摄，避免大面积遮挡")`。保留现有 `status/overall_score` 键，overall_score 改为由各信号的标定分位数映射合成（旧字段语义不变：仍是 0–1 越高越好）。

**阈值标定**（解决"拍脑杙"）：在合成扰动语料上，以"下游指标是否达标"（定位 P90 ≤ 0.1×pitch 且定量 MAE ≤ 目标）为真值标签，对每个信号取保形分位数阈值；用少量真实金标图验证覆盖率。QC 本身也被评估（§8 的门控 ROC）。

**单元级**：flags_i（§2.2）+ confidence_i 直接进 values.csv 与 grid_points，约定下游统计"应剔除 flags 非空单元或按 confidence 加权"。

## 8. 评估指标体系（证明"确实更好"）

三个测量轴 + 一个对比机制：

**A. 定位轴**（扩展现有工具）
- 保留：mean/median/P90/max/RMSE px、5px/10px 通过率；
- 新增：**按间距归一的误差（% pitch）**，使 10×10 与 15×15、不同分辨率可比；
- 新增：**退化曲线**——误差随扰动强度（旋转 0–10°、透视 0–15°、模糊 σ 0–5、光照梯度 0–50%、遮挡单元数 0–20）的曲线及其曲线下面积（AUC），对比新旧版本；
- 新增：兜底档位触发率、候选支撑率分布（语料级）。

**B. 定量轴**（全新，渲染真值使其可能）
- **准确性**：渲染器按已知光度量生成单元（含梯度序列），报告校正后读数的 MAE、R²、Spearman 单调性（梯度序列上的秩相关，衡量"能否保序"——多数下游分析真正依赖的性质）；
- **重复性**：同一目标多次渲染（仅随机噪声/微小位姿差异）读数的变异系数 CV%；
- **跨光照一致性**（问题 1 的直接度量）：同一目标在 N 种光照场（方向、强度、色温）下，校正后读数的最大相对偏差；raw 与 corrected 并报，差值即校正收益；
- **隔离性**（问题 3/4 的直接度量）：注入遮挡/高光于部分单元后，**未受影响单元**的读数变化必须 < 阈值（证明污染不扩散），受影响单元必须被 flags 命中（见 C）。

**C. 质量控制轴**
- 帧级门控 ROC/AUC（真值：该图下游指标是否达标）；
- 单元级 flags 的精确率/召回率（真值：渲染时注入的污染清单）。

**D. A/B 回归机制**
- 固定种子的扰动语料入库（`benchmarks/` 清单 + 生成脚本，不入库大图，按需再生成）；
- 一条命令跑双版本对比，输出逐指标增减表；CI 中设"不得回归"红线（关键指标劣化 > x% 即失败）。
- 验收样例：**"V2 相对 V1：跨光照最大偏差从 a% 降到 b%，旋转退化曲线 AUC 改善 c%，全部旧测试通过"**——这就是"证明确实更好"的标准句式。

## 9. 三阶段实现计划

**短期（基础设施 + 定量地基，纯传统 CV，估计 1–2 个迭代）**
1. 扰动渲染器 + 基准语料清单 + A/B 对比脚本 + 指标归一化（E1/E2/E3）；
2. 环形背景差分 + 光照场估计与平场校正（P1/P2 的主体收益）；
3. 逐点 source/confidence、逐单元 flags/SNR（L5/P4/P5/Q3）；
4. QC v2：reasons/suggestions + 新信号接入（Q1/Q2），阈值先用保守缺省；
5. result.json/values.csv 增量字段落地（§2.3），全部旧测试保持通过。
   - 验收：跨光照一致性、隔离性两条新指标建立基线并展示 corrected vs raw 的量化收益。

**中期（几何升级 + 标定闭环）**
1. 晶格光束法平差（单应 + 可选 k1，IRLS + 收缩窗口迭代精修）替换仿射一致性内核，`lattice_consistency` 字段语义兼容填充（L2/L3/L4）；
2. 候选支撑率硬校验接入 QC；
3. 自适应 ROI 掩膜 + 高光像素剔除（P3）；
4. 保形阈值标定流程 + 蜕变测试常驻化；
5. 移动端时间预算测量脚本（桌面模拟 + 单线程强制），发现超支模块。
   - 验收：透视/畸变扰动的退化曲线 AUC 显著改善；QC 门控 AUC ≥ 0.9（合成语料）。

**长期（可选学习兜底 + 端侧工程化）**
1. SAM 轻量变体接入区域兜底槽（零训练，评估触发率与收益后决定是否默认启用）；
2. 若传统精修在真实图上出现平台期：合成域训练的轻量点精修网络（≤2M 参数，int8）；
3. OpenCV Mobile 参考移植 + golden parity 测试；
4. 异常检测探索（统计法优先，特征法仅在必要时）。

## 10. 优先级排序

**最优先（没有它们其他工作无法证明价值）**：
1. 评估基准与 A/B 机制（§8/短期-1）——所有后续改动的"秤"；
2. 自参照光度校正 + 逐单元状态（短期-2/3）——距离"稳定定量"目标缺口最大、收益最直接；
3. QC v2 reasons（短期-4）——低成本高价值，直接改善可用性。

**次优先**：晶格光束法平差（中期-1/2）——当前几何在样例上已达 0.1px，其收益要在更强扰动语料上才能显现，因此排在基准之后。

**可暂缓**：一切深度模型（SAM 兜底、点精修网络）——传统链路的鲁棒性上限还没探到；移动端工程化——先用预算表约束设计，真实移植放到接口冻结后；异常检测特征法——统计法大概率够用。

## 11. 风险与开放问题

1. **乘性 vs 加性光照校正的选择**依赖成像链路是否近线性——设计上两者并行输出，由基准数据决定默认，避免提前站队；
2. **环形背景与相邻单元的间距**在 15×15（间距小）下更紧张，环半径参数需按 pitch 自适应并在渲染语料上验证无串扰；
3. **k1 径向项的可辨识性**：仅当扰动语料证明其残差可观测时才默认启用，否则固定为 0（模型选择由 BIC/交叉验证在基准上决定）；
4. **SAM 兜底的端侧成本**：先在桌面评估触发率——若 <2% 的图需要兜底，端侧可选择"拒绝 + 提示重拍"而非部署模型；
5. **保形标定的标定集规模**：真实金标图极少时以合成语料为主、真实图只做覆盖率抽查，需在文档中明示统计局限。
