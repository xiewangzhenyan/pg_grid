# 比色标定板样例（AFP 夹心免疫 + 酶促显色）

一组仿真生成的比色标定板图像，带完整真值，用于验证"图像 → 浓度"这条链路。

## 文件

| 文件 | 内容 |
|---|---|
| `plate.jpg` | 标定板。每行一个 AFP 浓度（0 及 0.5–500 ng/mL 等比 14 档），行内 15 个重复孔 |
| `plate_blank.jpg` | **配对空白图**。同一批固定图案噪声，用于算吸光度 |
| `zero.jpg` | 零浓度板。分析物为 0，只剩非特异结合本底——检出限由它决定 |
| `plate_detected.jpg` | 算法输出：矫正后图像叠加 225 个 ROI 与拟合中心 |
| `plate_truth.json` / `zero_truth.json` | 逐孔真值（显色产物浓度、透射率、吸光度、孔中心坐标） |
| `calibration_report.json` | 回收率、CV、LOD、LOQ、可用量程 |
| `read_plate.py` | 从图像文件复现整条读数链路 |

`plate_blank.jpg` 不是可选项。比色的被测量是 `A = −log10(I_sample / I_blank)`，
没有空白就只有一个被曝光、照明分布和 EL 光谱共同污染的灰度值。

## 复现

```bash
python examples/color/read_plate.py
```

脚本只吃图像文件和"每行加了哪个浓度的标准品"这一个配板时已知的量；
真值 JSON 只在最后比对时打开。实测输出：

**可用量程 0.5–20.6 ng/mL**（回收率 80–120% 且 CV<20%），LOD 0.18 ng/mL。
20 ng/mL 以上回收率上偏，是抗体结合饱和（模型取 K_D = 20 ng/mL），
不是光学问题——对策是稀释样品，不是改读数。

## 两个非显然的结论

**标定曲线要用 5PL，不能用常规的 4PL。** 分析物到读数是两级串联：抗原
抗体结合的 Langmuir 饱和（这级确实是 4PL），再叠一级多色光造成的吸光度
压缩。实测吸光度相对结合分数的比值从 1.000 单调降到 0.793，硬套 4PL
会在中段留下 10–38% 的系统性回收率偏高，合格点从 6/14 掉到 2/14。

**显色不要显到底。** 显色产物减半后，可用量程从 2.5–35 ng/mL 变成
0.5–20.6 ng/mL，0.5 ng/mL 处的回收率从 74% 升到 93%、CV 从 57% 降到 16%。
0.5 mm 液层逼着用高显色浓度才出吸光度，而那正好落进压缩区；显色浅一些，
曲线在低端更陡，低端反而更准。

## 生成方式

```python
from pg_colori_sim import ColorimetricConfig, CHROMOPHORES, Chromophore, PlasmonResonance
from pg_calibration import ImmunoassayResponse, calibration_run, log_series
```

配置：15×15、TMB 酸终止黄色产物（450 nm）、0.5 mm 液层、金阵列消光叠加
（峰 650 nm / FWHM 200 / 深度 0.40）、EL 背照带梯度与蜂窝纹、2° 旋转、
透视 0.018、桶形畸变 −0.055、离焦 σ1.1、JPEG 质量 92。

参数是按典型手机成像取的**估计值**，不是实测标定。图像用于验证算法链路，
不能直接当作该器件真实性能的预测。
